# Nagar360 — Project Brief

## Overview
**Nagar360** ("Namma Nagar, Namma Poruppu" / "See It. Report It. Improve It.") is an AI-powered civic complaint platform and civic social network for Indian cities, with Chennai as the default demo city.

Citizens can report civic issues (potholes, garbage, broken streetlights, water leakage, blocked drains, etc.), support complaints with upvotes, comment with local knowledge, track ticket status, and confirm resolution.
Authorities can view complaints on interactive maps, filter by ward/locality/status/severity, assign to departments, post official updates, detect duplicates, and track resolution metrics.
